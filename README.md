# Blackbit landing

A single-page introduction to Blackbit Zero, VOID, and the forthcoming Bay marketplace. The page leads with authorized offensive-security work, uses the supplied product lockups, and treats the Three.js field as an illustration of scope rather than live security telemetry.

## Local preview

```bash
npm ci --ignore-scripts
npm start
```

Open `http://localhost:4173`. Run `npm test` for navigation, scene lifecycle, and local asset checks. The server binds to `127.0.0.1` for preview.

## Product and claims boundary

Zero is presented as an agentic security workspace, VOID as a model gateway and console, and Bay as coming soon. The site does not claim a public Zero download, a live Bay marketplace, blanket model confidentiality, universal zero retention, TEE-backed inference, or a comparative benchmark score. The page has no external access or contact CTA because no product-owned destination was verified for this release.

The animated field contains seeded, synthetic geometry. It does not receive or depict target data, model responses, engagement scope, or evidence. Touch, reduced-motion, save-data, and unavailable WebGL states retain a static composition and the same text content.

## Typography

The intended brand hierarchy is Proto Mono for headers and interface labels, Die Grotesk A for body text, and Die Grotesk B for supporting statements. Martian Mono and IBM Plex Sans are technical fallbacks only. No proprietary font files are included in this public source tree, so a browser without the licensed faces installed or served will display the fallbacks. Exact public rendering requires webfont grants covering the eventual domain and the authorized WOFF2 files; the private organization repository alone does not establish those rights.

The Zero, VOID, and Bay SVGs are the supplied brand lockups, kept unmodified. The compact header/footer wordmark uses the master portion of the supplied lockup without the product suffix.
