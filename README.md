# omp replica

A hand-built recreation of the omp landing page: Geist and JetBrains Mono typography, pixelated particle field, magenta/cyan sweep, install method tabs, provider marquee, and interactive sidecar session previews.

## Run locally

```bash
npm start
```

Then open `http://localhost:4173`.

The page is a dependency-free static site. The preview rail uses the public omp session clips when a browser has network access; the landing page itself still renders without them.
